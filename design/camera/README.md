# Sky Camera product assets

These are branded **concept illustrations** created for the current redesign so implementation does not block on missing photography. They are not a technical drawing of a specific third-party camera model. Replace them later with approved photography if exact hardware representation is required.

## Files
- `sky-camera-tower-product.svg/png` — full-height product visual for Section 07.
- `sky-camera-tower-hero.svg/png` — hero version with subtle scan arcs.
- `sky-camera-tower-card.svg/png` — square visual for Camera / Fusion configuration cards.
- `sky-camera-sensor-array-detail.svg/png` — crop for technology / feature panels.
- `sky-camera-tower-blueprint.svg/png` — technical line-art decorative variant.
- `camera-hub-connectors.svg` — subtle hero / ecosystem connector paths.

## Usage
Prefer SVG for web. PNG is included for easy preview and fallback. Place the assets on the existing near-black Sky Guard background; do not add a white tile or stock-photo backdrop.
